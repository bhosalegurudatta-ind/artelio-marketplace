1. Executive Summary & Design Philosophy

Artelio is an advanced, high-performance web marketplace connecting independent visual artists with collectors across India and globally. The platform is engineered to dismantle the two primary barriers in digital and traditional art commerce: unauthorized master asset theft and collector uncertainty regarding physical/digital authenticity.

Core Architectural Innovation: Zero-Custody Model
Unlike traditional platforms that store high-resolution, unwatermarked master artwork in publicly addressable directories, Artelio enforces a Zero-Custody Architecture. The public edge servers index exclusively low-resolution previews embedded with indelible tiled SVG watermarks. High-resolution master assets remain encrypted in creator-controlled vaults and are released exclusively upon authenticated escrow payment.
  • Zero-Custody Master Storage: Edge nodes never expose original master files to public HTTP crawlers or scrapers.
  • 64-bit Perceptual Provenance (dHash):** Every artwork upload is fingerprinted using a perceptual difference hash algorithm and permanently anchored to the creator's identity in the immutable registry.
  • Multimodal RAG-Assisted AI Studio: Google Gemini multimodal models utilize the artist's existing portfolio as exemplar style context to generate signature-preserving variations.
  • Automated Escrow & 90/10 Platform Payout: Collector funds are held in milestone escrow; after buyer receipt, 90% is settled directly to artist UPI/bank accounts with 10% platform commission.
  • Interactive AR Room Visualizer: Client-side HTML5 canvas projection visualizes artworks against realistic living room, bedroom, and gallery walls with real-world dimensional scaling.

4. Zero-Custody Architecture & Provenance Protocol

Artelio establishes an indelible audit trail for fine art through three intertwined mechanisms:

1. Raw Upload & Watermark Master uploads are processed on edge. A 1000px preview is overlaid with an SVG geometric pattern watermark and pushed to the public CDN.
2. 64-bit dHash Hashing Pixels are mapped to a 9x8 matrix. Grayscale horizontal gradients generate a 64-bit fingerprint recorded in the provenance database.
3. Public Verification Portal Auditors match CoA numbers or upload images. The system calculates Hamming distances (≤ 16 bits) to verify authenticity instantly.

Mathematical Basis of the Perceptual Hash (dHash)

Unlike conventional cryptographic algorithms (SHA-256) where flipping a single byte causes a 100% cascade change, Artelio's perceptual hash evaluates low-frequency visual topology:

dHash = ∑y=0..7 ∑x=0..7 [ I(x, y) > I(x+1, y) ] · 2(y · 8 + x)

Similarity between an uploaded image hash Hquery and registry hash Hart is evaluated via Hamming Distance:

Dist(H1, H2) = CountBits(H1 ⊕ H2) ≤ 16 ⇒ Match Confidence ≥ 75%

7. Security, Authentication & Governance

Artelio maintains strict security separation across all layers:

  • Asymmetric JWT Validation: Requests carry Supabase Bearer tokens verified cryptographically by serverless route handlers.
  • Google OAuth 2.0 Integration: Synchronizes verified social credentials into internal profiles via dedicated server-side endpoints (`/api/auth/sync`).
  • Immutable Role Guards: Administrative actions (moderation, dispute resolution, fee adjustment) require validated `role = 'admin'` records in the database, preventing client-side spoofing.
  • HMAC Webhook Signatures: Razorpay payment hooks are verified using `crypto.createHmac('sha256', secret)` before orders transition to `paid` status.

8. Quality Assurance & Verification Protocol

  1. Type Integrity: Strict TypeScript compilation (`npx tsc --noEmit`) validates 100% of route handlers and components with zero type errors.
  2. Automated dHash Registry Backfill: All catalog artworks maintain pre-computed 64-bit difference hashes for instantaneous sub-10ms auditor comparisons.
  3. Continuous Deployment: Direct integration between GitHub `main` and Vercel guarantees zero-downtime rolling releases with global edge distribution.
